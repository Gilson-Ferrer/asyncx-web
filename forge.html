First Strike Challenge

Compilando seu primeiro binário

O Gonx Forge OS vem somente com as ferramentas básicas de construção, e como primeiro desafio, compile o nload para monitorar o tráfego de rede em tempo real.

# 1. Baixe o código fonte
cd /sources && wget http://www.roland-riegel.de/nload/nload-0.7.4.tar.gz --no-check-certificate

# 2. Extraia os arquivos
tar -xvf nload-0.7.4.tar.gz && cd nload-0.7.4

# 3. Configure o ambiente e compile
./configure --prefix=/usr && make

# 4. Instale no sistema
make install

# 5. Execute
nload
